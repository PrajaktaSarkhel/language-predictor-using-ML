REST API Specifications

Easily connect downstream pipelines or microservices to the real-time inference server.

POST /api/predict
cURL Request 
curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Bonjour tout le monde!",
    "top_k": 3
  }'
Python Client (requests) 
import requests

res = requests.post("http://localhost:5000/api/predict", json={
    "text": "नमस्ते दोस्तों, आप कैसे हैं?",
    "top_k": 3
})
data = res.json()
print(f"Language: {data['predicted_language']} ({data['confidence']}%)")
