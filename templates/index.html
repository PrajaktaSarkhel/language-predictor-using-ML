⚡ REST API Integration Guide

Integrate real-time language detection into your downstream microservices, web apps, or pipelines using JSON HTTP endpoints.

1. Detect Language Endpoint

POST /api/predict

curl -X POST http://localhost:5000/api/predict \ -H "Content-Type: application/json" \ -d '{"text": "Bonjour, comment allez-vous aujourd hui?", "top_k": 3}'

Sample JSON Response

{ "success": true, "predicted_language": "French", "confidence": 98.74, "code": "fr", "native": "Français", "flag": "🇫🇷", "family": "Indo-European (Romance)", "script": "Latin", "top_predictions": [ { "language": "French", "confidence_percent": 98.74, "native": "Français", "flag": "🇫🇷" }, { "language": "Spanish", "confidence_percent": 0.82, "native": "Español", "flag": "🇪🇸" } ] }

2. Python Integration Example

import requests url = "http://localhost:5000/api/predict" payload = {"text": "नमस्ते, आप कैसे हैं?"} response = requests.post(url, json=payload) data = response.json() print(f"Detected: {data['predicted_language']} ({data['confidence']}%) {data['flag']}")
